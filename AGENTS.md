# Difftest Working Guidelines

Before working in this repository, determine whether the task is a potentially complex, multi-file change or requires iterative testing/debugging. If so, review the relevant files in `docs/` as needed before proceeding.

For complex tasks, follow the plan/progress workflow defined in [`docs/developers/workflow.md`](docs/developers/workflow.md): create a plan, create a progress log, execute in phases, and confirm ambiguities with the user when necessary.
