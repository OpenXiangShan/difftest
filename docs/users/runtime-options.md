# Runtime Options

This page summarizes runtime options commonly used by DiffTest emulator users. The executable generated by a particular build is the final source of truth. Run it with `--help` to see the options compiled into that build.

## Common EMU Options

### Workload and Reference Model

| Option | Description |
|--------|-------------|
| `-i, --image=FILE` | Load the workload image |
| `--diff=PATH` | Enable differential checking with a reference-model `.so` |
| `--no-diff` | Run the DUT without reference-model checking |
| `-r, --gcpt-restore=FILE` | Override the checkpoint restore image |
| `--load-snapshot=PATH` | Restore a saved simulation snapshot |

### Execution Limits

| Option | Description |
|--------|-------------|
| `-C, --max-cycles=NUM` | Stop after `NUM` simulation cycles |
| `-I, --max-instr=NUM` | Stop after `NUM` committed instructions |
| `-W, --warmup-instr=NUM` | Skip the first `NUM` instructions during statistics |
| `-D, --stat-cycles=NUM` | Set the statistics dump interval |

### Logging and Tracing

| Option | Description |
|--------|-------------|
| `-b, --log-begin=NUM` | Start detailed logging at cycle `NUM` |
| `-e, --log-end=NUM` | Stop detailed logging at cycle `NUM` |
| `--dump-ref-trace` | Dump the reference-model trace during the logging window |
| `--dump-commit-trace` | Dump the DUT commit trace |
| `--dump-difftrace=NAME` | Dump the DiffTrace stream |
| `--load-difftrace=NAME` | Replay a DiffTrace stream |
| `--iotrace-name=NAME` | Load or dump an IOTrace stream |

### Waveforms

| Option | Description |
|--------|-------------|
| `--dump-wave` | Dump the logging window as a waveform |
| `--dump-wave-full` | Dump the waveform from cycle zero through the logging end |
| `--wave-path=FILE` | Select the waveform output path |

Waveform runtime options only work when the executable was built with waveform support, normally `EMU_TRACE=1` for VCD or `EMU_TRACE=fst` for FST.

### Randomness and Memory

| Option | Description |
|--------|-------------|
| `-s, --seed=NUM` | Set the simulation seed |
| `--random-mem` | Fill memory from a seed-initialized LFSR before loading the image |
| `--ram-size=SIZE` | Select simulated memory size, for example `8GB` or `128MB` |
| `--copy-ram=OFFSET` | Duplicate RAM at another offset |

### Footprints

| Option | Description |
|--------|-------------|
| `--as-footprints` | Interpret the input as a memory-access footprint image |
| `--dump-footprints=NAME` | Dump accessed blocks as a footprint image |
| `--dump-linearized=NAME` | Convert a footprint image to a linear image |

### Snapshots and Forking

| Option | Description |
|--------|-------------|
| `--enable-fork` | Enable periodic LightSSS snapshots and replay after a failure |
| `--fork-interval=NUM` | Set the snapshot interval in seconds |
| `--enable-snapshot` | Enable the backend snapshot interface |

Do not combine `--enable-fork` with `-b`, `-e`, `--dump-wave`, or `--dump-ref-trace`. Their interaction is not defined.

### Optional Debug Features

| Option | Description |
|--------|-------------|
| `--dump-db` | Dump the ChiselDB output when built with ChiselDB |
| `--db-path=FILE` | Select the database path |
| `--dump-coverage` | Dump coverage when the build supports it |
| `--ipc-interval=NUM` | Draw an IPC curve when built with IPC support |

Options for features that were not compiled into the executable are usually ignored with a warning.

## Common simv Arguments

| Argument | Description |
|----------|-------------|
| `+workload=FILE` | Load the workload image |
| `+diff=PATH` | Enable differential checking |
| `+no-diff` | Disable differential checking |
| `+max-cycles=NUM` | Stop after a cycle limit |
| `+max-instrs=NUM` | Stop after an instruction limit |
| `+b=NUM` | Start logging at cycle `NUM` |
| `+e=NUM` | Stop logging at cycle `NUM` |
| `+seed=NUM` | Set the random seed |
| `+random-mem` | Enable random memory initialization |
| `+dump-wave` | Dump a waveform when built with waveform support |
| `+no-squash` | Disable squash |
| `+squash-size=NUM` | Set the maximum fused instruction count |
| `+ram_size=SIZE` | Select simulated memory size |

## Availability

The source of truth for EMU options is [`src/test/csrc/common/args.cpp`](../../src/test/csrc/common/args.cpp). Backend wrappers can expose additional plusargs or ignore an option that is unavailable in the current build.
